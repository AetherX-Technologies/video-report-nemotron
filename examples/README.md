# Examples

`QggkUtXNkPo/` contains a generated final report for a public YouTube video:

- `report.md`: final Markdown report
- `report.html`: rendered HTML report
- `report.pdf`: printable PDF report
- `frames/`: selected frames referenced by the report

The example is included to show the expected output shape. Raw downloaded media, ASR model weights, OCR debug dumps, and local runtime files are intentionally excluded.
